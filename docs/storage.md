# MARK AI OS — Storage

## Overview

MARK uses a two-layer storage abstraction:

1. **Storage layer** — key-value store for structured data (chat, memory, settings, state)
2. **Vector layer** — embedding-based search for semantic retrieval

Both layers are pluggable; swapping backends requires only changing environment variables.

---

## Storage layer

### Selection

| `DATABASE_PROVIDER` | Backend               | Best for                        |
|---------------------|-----------------------|---------------------------------|
| `sqlite` (default)  | JSON files on disk    | Local dev, single-user          |
| `postgres`          | PostgreSQL via SQLAlchemy | Production, multi-user      |

PostgreSQL is auto-selected when `DATABASE_URL` is set.

### LocalStorageProvider (default)

Stores each namespace as a JSON file under `STORAGE_DIR` (default: `.mark_storage/`).

```
.mark_storage/
├── chat.json
├── memory.json
├── settings.json
├── agent_state.json
└── project.json
```

No dependencies. Thread-safe via per-namespace locks.

### PostgresStorageProvider

Single table `mark_storage(namespace, key, value JSONB, created_at, updated_at)`.

```bash
DATABASE_PROVIDER=postgres
DATABASE_URL=postgresql://user:pass@localhost:5432/mark
```

Requires: `pip install sqlalchemy psycopg2-binary`

Tables are created automatically on first startup.

### Usage

```python
from smartagent.storage import get_storage

store = get_storage()

# Read / write / delete
store.set("settings", "theme", {"dark": True})
val = store.get("settings", "theme")   # → {"dark": True}
store.delete("settings", "theme")

# List
keys    = store.list_keys("chat")
records = store.list_records("chat")   # → list[StorageRecord]

# Health
status = store.health()   # → {"status": "ok", ...}
```

### Namespaces

| Namespace     | Contents                               |
|---------------|----------------------------------------|
| `chat`        | Conversation messages and sessions     |
| `memory`      | Long-term memory entries               |
| `settings`    | User and system configuration          |
| `agent_state` | Running task state                     |
| `project`     | Project metadata and profiles          |

## Vector layer

### Selection

| `VECTOR_PROVIDER` | Backend               | Best for                        |
|-------------------|-----------------------|---------------------------------|
| `keyword` (default) | TF-IDF in-memory    | Zero deps, fast for small sets  |
| `chroma`          | ChromaDB local store  | Local dev with semantic search  |
| `pgvector`        | PostgreSQL + pgvector | Production, persistent vectors  |

### KeywordProvider (default)

Pure-Python TF-IDF cosine similarity. Zero external dependencies.

### ChromaProvider

Persistent ChromaDB store. Embeddings generated by the active LLM provider.

```bash
VECTOR_PROVIDER=chroma
CHROMA_PATH=.mark_chroma
pip install chromadb
```

### PGVectorProvider

PostgreSQL + pgvector extension. Requires PostgreSQL 15+ with pgvector installed.

```bash
VECTOR_PROVIDER=pgvector
DATABASE_URL=postgresql://...
pip install pgvector sqlalchemy psycopg2-binary
```

PostgreSQL setup:
```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

Tables are created automatically on first startup.

### Usage

Agent code never knows which backend is active:

```python
from smartagent.vector import get_vector_store

vs = get_vector_store()

# Index documents
vs.add(
    texts=["MARK is an AI engineer", "Python is great"],
    ids=["doc1", "doc2"],
    metadatas=[{"source": "readme"}, {"source": "readme"}],
)

# Search
results = vs.search("AI software engineer", n=3)
for r in results:
    print(r.id, r.score, r.text[:60])

# Count and delete
print(vs.count())
vs.delete(["doc1"])
```

## Adding a new backend

### New storage backend

```python
# smartagent/storage/my_storage.py
from smartagent.storage.base import StorageProvider, StorageRecord

class MyStorageProvider(StorageProvider):
    def get(self, namespace, key): ...
    def set(self, namespace, key, value): ...
    def delete(self, namespace, key): ...
    def list_keys(self, namespace): ...
    def list_records(self, namespace): ...
```

Register in `smartagent/storage/factory.py`.

### New vector backend

```python
# smartagent/vector/my_vector.py
from smartagent.vector.base import VectorProvider, SearchResult

class MyVectorProvider(VectorProvider):
    def add(self, texts, ids, metadatas=None): ...
    def search(self, query, n=5): ...
    def delete(self, ids): ...
    def count(self): ...
```

Register in `smartagent/vector/factory.py`.
