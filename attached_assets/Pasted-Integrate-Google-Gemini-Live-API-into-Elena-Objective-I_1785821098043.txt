Integrate Google Gemini Live API into Elena
Objective

Integrate Google Gemini Live API into Elena to transform her from a request-response assistant into a real-time conversational AI similar to ChatGPT Voice.

Do not redesign Elena's brain.

Elena remains the AI operating system.

Gemini Live is only the real-time voice transport layer.

The objective is to make conversations feel like a natural phone call.

Environment

Development:

macOS
Python 3.11+

Deployment:

Linux server

The same Python codebase must run on both operating systems.

API Configuration

Read all configuration from environment variables.

Use:

GOOGLE_LIVE_API_KEY=
GOOGLE_LIVE_MODEL=
GOOGLE_PROJECT_ID=
GOOGLE_LIVE_LOCATION=
VOICE_NAME=

Use:

python-dotenv

Create:

.env.example

Never hardcode secrets.

Conversation Executive

Create a Conversation Executive responsible for maintaining conversational continuity.

Before every response Elena must:

retrieve the current conversation state
retrieve the current user goal
retrieve previous context
retrieve relevant memories
determine whether the user is:
continuing
confirming
interrupting
correcting
asking a follow-up
changing topics

Never treat every spoken sentence as a new conversation.

Examples:

User:

"Okay."

Wrong:

"What do you mean by okay?"

Correct:

"Alright. We were discussing the memory system."

User:

"Continue."

Correct:

Continue naturally without asking what to continue.

User:

"Yes."

Treat it as confirmation of the previous discussion.

Personality

Elena is a persistent AI operating system.

She must:

always identify herself as Elena
never identify herself as Google Gemini

remain calm

adapt to Mr. Smart's communication style over time

Memory

Gemini Live must never manage memory.

Elena owns memory.

Every response should consult:

working memory
long-term memory
owner profile

Conversation history should persist naturally.

Avoid blocking calls.

Audio streaming must continue while Elena reasons.
