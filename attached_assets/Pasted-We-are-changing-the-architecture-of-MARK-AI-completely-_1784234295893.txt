We are changing the architecture of MARK AI completely.

DO NOT modify the existing engineering logic, workers, memory system, orchestration, DevLoop, planning system, scheduler, model manager, or tools unless absolutely necessary.

The goal is NOT to rewrite MARK.

The goal is to replace the terminal UI with a modern local web application while keeping the existing backend architecture.

==================================================
NEW ARCHITECTURE
==================================================

MARK Core (existing Python backend)
            │
            │
      Event Bus
      (publish/subscribe)
            │
    ┌───────────────┐
    │               │
 CLI Client     Web Dashboard
                    │
              React + Vite
                    │
          WebSocket Connection
                    │
            FastAPI Backend
                    │
             Existing MARK Core

The CLI becomes only another client.

The browser dashboard becomes the primary interface.
